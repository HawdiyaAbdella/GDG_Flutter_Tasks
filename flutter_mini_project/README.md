# Flutter News App Mini Project

## How to Run

### Prerequisites
- [Flutter SDK](https://flutter.dev/docs/get-started/install) installed and added to your PATH.
- An Android Emulator (via Android Studio) or iOS Simulator (Xcode, macOS only).

### 1. Install Dependencies
Open a terminal in the project folder and run:
```bash
flutter pub get
```

### 2. Run the App
To start the app on your connected device or emulator:
```bash
flutter run
```

### 3. Run in VS Code
You can also run the app directly from VS Code:
1. Open `lib/main.dart`.
2. Press **F5** or go to **Run > Start Debugging**.
